企画のまとめ（案）

Unityちゃんが「カード＝1行のコード」を1ターンに1枚実行して、宇宙にわいたバグ（本物のエラー名を持つ敵）をデバッグする、ターン制カードバトル。遊ぶたびに、Unityの本に出てくる言葉の意味が「効果」として体に入る、自分用の教材ゲームです。

企画のことば → このサンプルでの形

企画にあったことサンプルではこうした
Unityちゃんを操作しながら用語を覚えるカードを選ぶとUnityちゃんがそのコードを「実行」する。カードにはゲームでの効果とUnityでの本当の意味を並べて表示。
5枚の手札を互いのターンで切りあう手札5枚・1ターン1枚。敵は「次に何をするか」を予告するので、どのカードで受けるかを考える。
Unityちゃんが発する弾毎ターン自動で1ダメージの通常弾。Instantiate や for で追加の弾、AddForce で通常弾を強化。
相手のHPは通常見えないHPは「???」表示。Debug.Log を使うとHPと弱点がConsoleに出て、以後見える。Destroy（HP5以下で一撃）と組み合わせると気持ちいい。
「Is Trigger をオン」で弾をすり抜けそのまま採用。Inspectorのチェックが実際に入り、弾が体を通り抜ける演出つき。
「DamageInfo」で弱点を読むDebug.Log に置きかえ。DamageInfo はUnityに最初からある言葉ではなく、人が自作する名前なので、本で必ず出会う Debug.Log の方が学びにつながる。
「isStunned」で敵を気絶採用。ただし「Unityの機能」ではなく自分で作る bool 変数として紹介（これ自体が学びになる）。
星空＝プログラミング画面の黒星空の背景に、コードエディタ風の色分け。右側はUnityエディタの Inspector / Console を模した画面。
ギャラクシアンが参考宇宙・虫型の敵・縦向きの画面という雰囲気だけ参考に。操作はシューティングではなくカード選択だけ。
セーブ機能なし3ステージを続けて遊ぶ。負けたらそのステージの最初から。

1ターンの流れ

  1. 手札が5枚になるまで山札から引く
  2. カードを1枚選んで実行（効果が出る／Consoleにコードが出る）
  3. Unityちゃんの通常弾（1ダメージ）が自動で飛ぶ
  4. 敵が予告どおりに行動する（攻撃・ガード・力をためる）
  5. Is Trigger や AddForce の効果が切れて、次のターンへ

ステージ敵くせ弱点本当は何？

本番で赤いエラーを見たときに「あ、ステージ1の敵だ」と思えれば、エラーがこわくなくなる、というねらいです。

「頭は小文字？大文字？」への答え

  • Unityの画面（Inspector）では Is Trigger（スペースあり・大文字）と表示される
  • コードでは isTrigger（小文字はじまり・つなげて書く）
  • C#の決まり：命令（メソッド）やクラスは大文字 → Instantiate Debug、変数や設定値は小文字 → hp isStunned
  • カードにはコードの書き方を使うと、本やコードと同じ見た目で覚えられる

覚えるためのしかけ

  • カードの解説は「このゲームでは」と「Unityでは」の2本立て
  • 使ったカードのコードが Console に1行ずつ流れる
  • Inspector のチェックや数字が、カードの効果で実際に変わる
  • 使ったカードが「用語ずかん」に登録される
  • Unity版では isTrigger カードが本当に Collider の Is Trigger を切りかえる（ゲームの効果＝本物の機能）
